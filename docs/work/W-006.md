# W-006 Registrar

- **Build:** takes an item from an adapter, hashes it, adds a location row, and for new content stores the original and enqueues the first job.
- **Done when:** the same bytes at two paths give one content row and two location rows, and the same path twice gives one of each.
- **Not now:** any adapter other than a test double. Note: for a binary file the parse processor writes the package; the registrar writes it only when an adapter already hands it markdown.
