# W-005 lake_core: object store and package IO

- **Build:** an object-store client using the key layout from the runtime section, plus functions to write and read a package.
- **Done when:** a write and read round trip matches byte for byte, writing an existing `rev` fails, and a manifest missing a required field is rejected.
- **Not now:** parsing; this item only stores what it is given.
